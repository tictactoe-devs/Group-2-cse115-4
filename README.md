❌⭕ A classic two-player Tic-Tac-Toe game. Designed with modularity, clean input validation, and real-time rendering.
---
## ✨ Features

*   **Clean Terminal UI:** Interactive 3x3 grid updated in real-time.
*   **Robust Input Validation:** Prevents players from overwriting existing spots or entering out-of-range values.
*   **Automated Win/Tie Detection:** Instantly recognizes horizontal, vertical, or diagonal wins, or flags a draw when the grid is full.
*   **Beginner-Friendly Architecture:** Written using fundamental C concepts (2D arrays, loops, functions, and conditional statements) without complex pointers or dynamic memory.
---
## 🛠️ Tech Stack

*   **Language:** C (C99 standard)
*   **Libraries Used:** `<stdio.h>` (Standard Input/Output)
